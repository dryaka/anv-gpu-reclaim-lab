# ANV GPU reclaim lab

Experimental investigation of Intel ANV Vulkan memory-budget accounting for GPU reuse-pool memory on a Fedora / Podman / Ollama setup.

The experiment is opt-in and hardware validation is pending. Work is reviewed on the `experiment/anv-gpu-reclaim` branch. See its project plan, environment manifest and inventory instructions before building or running anything.

Keep source trees, build output, images, models and raw machine evidence outside Git. This repository is public; review any evidence before committing it.
